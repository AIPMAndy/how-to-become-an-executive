# SOP · 做出一页经营决策测算

适用对象：正在处理「理解预算、成本与业务模型」的人。建议先完成相应章节：[理解预算、成本与业务模型](../guides/05-business.md)。

## 启动前（10分钟）

1. 把本次目标写成一句话：做出一页经营决策测算。
2. 建一个**只在本人设备保存**的文件夹；公司机密材料仍须留在获授权工作系统。
3. 复制关联模板 `templates/business-scenarios.csv`（可用Excel、Numbers或在线表格打开，但注意平台隐私授权）。
4. 预约必要的主管/HR/同事沟通；无法获得授权时只做公开信息研究。

## 五步执行清单（每项完成后再进入下一步）

### 第1步 · 看懂你的业务价值链

**操作：** 画出用户需求→交付环节→收入/成本/质量结果；标记你真正能影响的位置。
**验收：** 一张无敏感信息的业务价值链图。
**走不通：** 不负责收入可先从成本、效率、交付质量等经营指标入手。

- [ ] 第1步的凭证已核实，并留在私人安全位置

### 第2步 · 设计简单单位经济模型

**操作：** 为一个业务环节估算单位收入、直接成本、毛贡献，清楚标注估计与财务核定的区别。
**验收：** 一张算式透明的情景分析表。
**走不通：** 没有权限查财务数据时使用公开或经授权的数字作为情景假设。

- [ ] 第2步的凭证已核实，并留在私人安全位置

### 第3步 · 提交资源申请

**操作：** 用目标、备选方案、投入、可测收益、失效条件组织预算申请。
**验收：** 一页资源申请材料和指标复盘日期。
**走不通：** 结果不确定时先申请小规模试点，避免大笔预算赌方向。

- [ ] 第3步的凭证已核实，并留在私人安全位置

### 第4步 · 设计风险护栏

**操作：** 列出交付风险、人员风险、财务风险、客户风险四类，分配责任人与预警信号。
**验收：** 四栏风险登记表。
**走不通：** 对不可量化风险定义观察信号和升级路径。

- [ ] 第4步的凭证已核实，并留在私人安全位置

### 第5步 · 做一次停项判断

**操作：** 找到一个低价值工作，估算停止后节约的时间和损失，先征得相关负责人同意。
**验收：** 一份停止/继续/缩减方案及决策记录。
**走不通：** 不能单方取消关键交付，先做不影响外部承诺的试点。

- [ ] 第5步的凭证已核实，并留在私人安全位置

## 关键操作细化（完成需15—60分钟）

- **具体研究：** 把流水、收入、直接成本、毛利、增量成本分列。
- **现实校准：** 做乐观/基准/保守情景，写继续和止损条件。
- **证据等级：** A＝有合法可核验的书面/系统记录；B＝协作方可核对的纪要；C＝本人记忆或主观判断。C不可以包装为A。
- **怎么提问：** “我准备完成____，目前证据是____，缺口是____。你能否确认评价标准/授权边界/下一次反馈时间？”
- **失败时的止损：** 先列事实与不确定项，决定继续补资料、缩小试点或暂停；禁止为了凑结果伪造业绩/Offer。

## 交付包（建议不超过3页）

1. `business-scenarios.csv`：可复查的研究/决策记录。
2. 一页：背景、当前问题、数据口径、行动选择、完成日期。
3. 一页：关键反例、风险与下一步；涉及法律、聘用合同或重大财务风险先由相关专业人士核对。

## 质量门槛 / 自我审查

- [ ] 事实、推断、计划分别标记；不写保证结果。
- [ ] 每个数字都有单位、时间窗、归属、来源。
- [ ] 模板不包含真实密码、身份证号、客户信息和商业秘密。
- [ ] 至少写一个“当前假设失败会怎样”的替代动作。
