# SOP · 选定职业路径并设置止损条件

适用对象：正在处理「三分钟判断你适合哪条路线」的人。建议先完成相应章节：[三分钟判断你适合哪条路线](../guides/00-start.md)。

## 启动前（10分钟）

1. 把本次目标写成一句话：选定职业路径并设置止损条件。
2. 建一个**只在本人设备保存**的文件夹；公司机密材料仍须留在获授权工作系统。
3. 复制关联模板 `templates/career-tracks.csv`（可用Excel、Numbers或在线表格打开，但注意平台隐私授权）。
4. 预约必要的主管/HR/同事沟通；无法获得授权时只做公开信息研究。

## 五步执行清单（每项完成后再进入下一步）

### 第1步 · 定义目标岗位

**操作：** 在三个公开职位描述中找出“管理人数、业务收入/成本、预算权限、汇报对象、跨团队决策”五类信息；写出一个你想争取的具体岗位。
**验收：** 一张目标岗位卡：岗位名称、行业、城市、五项权责。
**走不通：** 搜不到高管岗位时，先找经理/总监岗位，向上一级反推职责。

- [ ] 第1步的凭证已核实，并留在私人安全位置

### 第2步 · 分清专业路线与管理路线

**操作：** 写下你近两年最有能量的工作：专业深耕、项目负责或人员管理；问两位了解你的人，自己最擅长哪一类。
**验收：** 一份“专家/项目负责人/人员管理者”三选一分析。
**走不通：** 不确定就先试带一个项目，不急着换管理头衔。

- [ ] 第2步的凭证已核实，并留在私人安全位置

### 第3步 · 建立能力基线

**操作：** 根据业务结果、人才培养、跨部门影响、预算管理、组织决策六个维度各打0~4分，每分附可核验例证。
**验收：** 能力差距雷达表和六条证据。
**走不通：** 没有例证就记0，先找工作场景实践。

- [ ] 第3步的凭证已核实，并留在私人安全位置

### 第4步 · 确认岗位权限边界

**操作：** 把你目前的决定权分成“我直接定、我建议后别人定、完全无权”三栏，记录典型事项。
**验收：** 一份授权边界清单。
**走不通：** 向主管核对职责而非擅自扩大权限。

- [ ] 第4步的凭证已核实，并留在私人安全位置

### 第5步 · 排除不值得的晋升

**操作：** 为升职可能增加的工作时间、地点变动、压力、团队责任和收入波动设置个人底线。
**验收：** 晋升红线表：最多三项不可接受条件。
**走不通：** 若岗位触碰红线，保留专业晋升或外部机会。

- [ ] 第5步的凭证已核实，并留在私人安全位置

## 关键操作细化（完成需15—60分钟）

- **具体研究：** 三条路线比较：专业专家、项目负责人、人员管理。
- **现实校准：** 与主管确认能否承担一个不涉及人事权限的试点。
- **证据等级：** A＝有合法可核验的书面/系统记录；B＝协作方可核对的纪要；C＝本人记忆或主观判断。C不可以包装为A。
- **怎么提问：** “我准备完成____，目前证据是____，缺口是____。你能否确认评价标准/授权边界/下一次反馈时间？”
- **失败时的止损：** 先列事实与不确定项，决定继续补资料、缩小试点或暂停；禁止为了凑结果伪造业绩/Offer。

## 交付包（建议不超过3页）

1. `career-tracks.csv`：可复查的研究/决策记录。
2. 一页：背景、当前问题、数据口径、行动选择、完成日期。
3. 一页：关键反例、风险与下一步；涉及法律、聘用合同或重大财务风险先由相关专业人士核对。

## 质量门槛 / 自我审查

- [ ] 事实、推断、计划分别标记；不写保证结果。
- [ ] 每个数字都有单位、时间窗、归属、来源。
- [ ] 模板不包含真实密码、身份证号、客户信息和商业秘密。
- [ ] 至少写一个“当前假设失败会怎样”的替代动作。
