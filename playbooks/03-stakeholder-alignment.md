# SOP · 无管理权的跨部门协作

适用对象：正在处理「拿到跨团队推动能力」的人。建议先完成相应章节：[拿到跨团队推动能力](../guides/03-influence.md)。

## 启动前（10分钟）

1. 把本次目标写成一句话：无管理权的跨部门协作。
2. 建一个**只在本人设备保存**的文件夹；公司机密材料仍须留在获授权工作系统。
3. 复制关联模板 `templates/decision-rights.csv`（可用Excel、Numbers或在线表格打开，但注意平台隐私授权）。
4. 预约必要的主管/HR/同事沟通；无法获得授权时只做公开信息研究。

## 五步执行清单（每项完成后再进入下一步）

### 第1步 · 画关键干系人地图

**操作：** 围绕一个业务目标找出使用者、决策人、资源方、风险控制方，记录对方关注点与同意标准。
**验收：** 至少8人的干系人表，避免写敏感个人信息。
**走不通：** 不知道利益诉求时预约访谈，不根据性格标签猜测。

- [ ] 第1步的凭证已核实，并留在私人安全位置

### 第2步 · 建立一页共识文档

**操作：** 写清问题、选项A/B、成本、边界、责任人和需要谁拍板，提前给相关人反馈。
**验收：** 有日期版本号的一页决策文档。
**走不通：** 分歧过大先缩小范围，明确哪些问题尚无证据。

- [ ] 第2步的凭证已核实，并留在私人安全位置

### 第3步 · 主持一次跨部门评审

**操作：** 会前收集分歧；会议上按事实、取舍、行动项走；会后24小时内记录责任人与截止日。
**验收：** 会议纪要及被相关人确认的行动项。
**走不通：** 无法拍板就列升级条件和决策人，不自行冒充授权。

- [ ] 第3步的凭证已核实，并留在私人安全位置

### 第4步 · 拆解一项资源冲突

**操作：** 记录资源不足导致的交付风险，量化优先级、替代方案和对其他团队的影响。
**验收：** 可讨论的资源取舍方案，不指责个人。
**走不通：** 没有数字就用影响等级并说明判断依据。

- [ ] 第4步的凭证已核实，并留在私人安全位置

### 第5步 · 积累被动认可证据

**操作：** 在项目结束时邀请相关协作者就具体行为给反馈，保留其愿意公开的部分。
**验收：** 3条具体反馈，包含场景和行为。
**走不通：** 不强求好评，负面反馈也记入成长计划。

- [ ] 第5步的凭证已核实，并留在私人安全位置

## 关键操作细化（完成需15—60分钟）

- **具体研究：** 列利益相关者和最终拍板者，在会议前收集阻碍。
- **现实校准：** 提出A/B选项，明确责任人和升级日期。
- **证据等级：** A＝有合法可核验的书面/系统记录；B＝协作方可核对的纪要；C＝本人记忆或主观判断。C不可以包装为A。
- **怎么提问：** “我准备完成____，目前证据是____，缺口是____。你能否确认评价标准/授权边界/下一次反馈时间？”
- **失败时的止损：** 先列事实与不确定项，决定继续补资料、缩小试点或暂停；禁止为了凑结果伪造业绩/Offer。

## 交付包（建议不超过3页）

1. `decision-rights.csv`：可复查的研究/决策记录。
2. 一页：背景、当前问题、数据口径、行动选择、完成日期。
3. 一页：关键反例、风险与下一步；涉及法律、聘用合同或重大财务风险先由相关专业人士核对。

## 质量门槛 / 自我审查

- [ ] 事实、推断、计划分别标记；不写保证结果。
- [ ] 每个数字都有单位、时间窗、归属、来源。
- [ ] 模板不包含真实密码、身份证号、客户信息和商业秘密。
- [ ] 至少写一个“当前假设失败会怎样”的替代动作。
