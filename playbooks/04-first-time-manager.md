# SOP · 完成首次授权与1:1反馈

适用对象：正在处理「学会带人和搭建团队」的人。建议先完成相应章节：[学会带人和搭建团队](../guides/04-people.md)。

## 启动前（10分钟）

1. 把本次目标写成一句话：完成首次授权与1:1反馈。
2. 建一个**只在本人设备保存**的文件夹；公司机密材料仍须留在获授权工作系统。
3. 复制关联模板 `templates/coaching-log.csv`（可用Excel、Numbers或在线表格打开，但注意平台隐私授权）。
4. 预约必要的主管/HR/同事沟通；无法获得授权时只做公开信息研究。

## 五步执行清单（每项完成后再进入下一步）

### 第1步 · 试行一对一沟通

**操作：** 经允许和授权与合作同事开展定期1:1，围绕目标、障碍、资源、成长四问。
**验收：** 匿名会议框架及解决的问题记录。
**走不通：** 没有管理权限时不越级做绩效评价。

- [ ] 第1步的凭证已核实，并留在私人安全位置

### 第2步 · 做任务授权矩阵

**操作：** 把五项任务按“必须自己做/可以辅导/可以授权”分层，明确质量标准和复核节点。
**验收：** 一份RACI或DACI矩阵。
**走不通：** 如果成员无时间，先与实际主管协商资源。

- [ ] 第2步的凭证已核实，并留在私人安全位置

### 第3步 · 练习建设性反馈

**操作：** 采用“具体情境→可观察行为→影响→共同确认下一步”的方式进行一次反馈。
**验收：** 反馈前后双方认同的下一步记录。
**走不通：** 情绪激烈时先延后，不做人格评判。

- [ ] 第3步的凭证已核实，并留在私人安全位置

### 第4步 · 设计新人带教计划

**操作：** 按第1周、第1月、第3月定义任务、导师、验收结果与反馈窗口。
**验收：** 一份新人90天带教模板。
**走不通：** 团队暂时不招人就先用于知识交接。

- [ ] 第4步的凭证已核实，并留在私人安全位置

### 第5步 · 识别管理伦理风险

**操作：** 检查是否存在抢功、歧视、越权访问、泄露薪资等问题，并设升级渠道。
**验收：** 一份管理风险自检清单。
**走不通：** 遇到违法违规线索，按公司合规机制及法定渠道处理。

- [ ] 第5步的凭证已核实，并留在私人安全位置

## 关键操作细化（完成需15—60分钟）

- **具体研究：** 在上级许可下挑一件风险可控的带教任务。
- **现实校准：** 以行为事实反馈，检查同事是否能独立交付。
- **证据等级：** A＝有合法可核验的书面/系统记录；B＝协作方可核对的纪要；C＝本人记忆或主观判断。C不可以包装为A。
- **怎么提问：** “我准备完成____，目前证据是____，缺口是____。你能否确认评价标准/授权边界/下一次反馈时间？”
- **失败时的止损：** 先列事实与不确定项，决定继续补资料、缩小试点或暂停；禁止为了凑结果伪造业绩/Offer。

## 交付包（建议不超过3页）

1. `coaching-log.csv`：可复查的研究/决策记录。
2. 一页：背景、当前问题、数据口径、行动选择、完成日期。
3. 一页：关键反例、风险与下一步；涉及法律、聘用合同或重大财务风险先由相关专业人士核对。

## 质量门槛 / 自我审查

- [ ] 事实、推断、计划分别标记；不写保证结果。
- [ ] 每个数字都有单位、时间窗、归属、来源。
- [ ] 模板不包含真实密码、身份证号、客户信息和商业秘密。
- [ ] 至少写一个“当前假设失败会怎样”的替代动作。
