# SOP · 把90天计划变成每周可执行任务

适用对象：正在处理「90天验证计划与长线维护」的人。建议先完成相应章节：[90天验证计划与长线维护](../guides/09-90days.md)。

## 启动前（10分钟）

1. 把本次目标写成一句话：把90天计划变成每周可执行任务。
2. 建一个**只在本人设备保存**的文件夹；公司机密材料仍须留在获授权工作系统。
3. 复制关联模板 `templates/weekly-review.csv`（可用Excel、Numbers或在线表格打开，但注意平台隐私授权）。
4. 预约必要的主管/HR/同事沟通；无法获得授权时只做公开信息研究。

## 五步执行清单（每项完成后再进入下一步）

### 第1步 · 第1–7天：确定下一站

**操作：** 选定一个目标层级、三个能力差距、一个可承担的业务场景。
**验收：** 一页90天目标清单。
**走不通：** 被日常事务打断时只保留最关键一项目标。

- [ ] 第1步的凭证已核实，并留在私人安全位置

### 第2步 · 第8–30天：建立证据

**操作：** 完成至少三张项目证据卡并与主管沟通一次评价标准。
**验收：** 三张证据卡及一次真实反馈。
**走不通：** 没项目就争取有明确边界的子任务。

- [ ] 第2步的凭证已核实，并留在私人安全位置

### 第3步 · 第31–60天：扩大影响范围

**操作：** 推动至少一次跨团队协作和一次一页纸决策建议。
**验收：** 会议行动记录及决策备忘录。
**走不通：** 无权推动时先争取负责人赞同。

- [ ] 第3步的凭证已核实，并留在私人安全位置

### 第4步 · 第61–90天：申请校准

**操作：** 更新能力评分、组织复盘，决定继续积累、内部竞聘还是外部验证。
**验收：** 90天复盘与下一季度计划。
**走不通：** 如果组织没有晋升机会，承认外部结构约束。

- [ ] 第4步的凭证已核实，并留在私人安全位置

### 第5步 · 每季度复核一次

**操作：** 观察业务成果、授权范围、健康与家庭成本、岗位机会是否变化。
**验收：** 季度复盘和三项下一步动作。
**走不通：** 长期无进展时改策略，不无限延长同一计划。

- [ ] 第5步的凭证已核实，并留在私人安全位置

## 关键操作细化（完成需15—60分钟）

- **具体研究：** 第1—2周建基线，第3—8周小试点，第9—12周复盘。
- **现实校准：** 对照证据而非感受决定继续/延长/转向。
- **证据等级：** A＝有合法可核验的书面/系统记录；B＝协作方可核对的纪要；C＝本人记忆或主观判断。C不可以包装为A。
- **怎么提问：** “我准备完成____，目前证据是____，缺口是____。你能否确认评价标准/授权边界/下一次反馈时间？”
- **失败时的止损：** 先列事实与不确定项，决定继续补资料、缩小试点或暂停；禁止为了凑结果伪造业绩/Offer。

## 交付包（建议不超过3页）

1. `weekly-review.csv`：可复查的研究/决策记录。
2. 一页：背景、当前问题、数据口径、行动选择、完成日期。
3. 一页：关键反例、风险与下一步；涉及法律、聘用合同或重大财务风险先由相关专业人士核对。

## 质量门槛 / 自我审查

- [ ] 事实、推断、计划分别标记；不写保证结果。
- [ ] 每个数字都有单位、时间窗、归属、来源。
- [ ] 模板不包含真实密码、身份证号、客户信息和商业秘密。
- [ ] 至少写一个“当前假设失败会怎样”的替代动作。
