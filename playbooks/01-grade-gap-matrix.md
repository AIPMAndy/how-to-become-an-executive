# SOP · 用岗位描述做职级证据矩阵

适用对象：正在处理「看懂晋升阶梯与岗位标准」的人。建议先完成相应章节：[看懂晋升阶梯与岗位标准](../guides/01-ladder.md)。

## 启动前（10分钟）

1. 把本次目标写成一句话：用岗位描述做职级证据矩阵。
2. 建一个**只在本人设备保存**的文件夹；公司机密材料仍须留在获授权工作系统。
3. 复制关联模板 `templates/level-gap.csv`（可用Excel、Numbers或在线表格打开，但注意平台隐私授权）。
4. 预约必要的主管/HR/同事沟通；无法获得授权时只做公开信息研究。

## 五步执行清单（每项完成后再进入下一步）

### 第1步 · 绘制本公司的岗位阶梯

**操作：** 询问公开的职级制度，画出当前→上一级→目标层级的职责差异，标注每一层的评价人。
**验收：** 一张只使用公开或获授权信息的职级图。
**走不通：** 无职级制度时用公开岗位JD对照，不获取内部保密资料。

- [ ] 第1步的凭证已核实，并留在私人安全位置

### 第2步 · 收集三份目标JD

**操作：** 从公开招聘页选三份目标岗位，逐条标记必须项、加分项、可培养项。
**验收：** 能力要求对照表至少10行。
**走不通：** 用同行岗位补充，不把单家公司要求当行业标准。

- [ ] 第2步的凭证已核实，并留在私人安全位置

### 第3步 · 访谈两位管理者

**操作：** 预约每人20分钟，问“岗位最难的决策、晋升看什么证据、常见失败原因”各一个问题。
**验收：** 两份经对方允许记录的匿名访谈摘要。
**走不通：** 无人愿意访谈则参加公开分享并标注为公开信息。

- [ ] 第3步的凭证已核实，并留在私人安全位置

### 第4步 · 形成能力差距前五项

**操作：** 用目标JD评分×差距大小×改善可控性排序，选择90天能补的前三项。
**验收：** 三项优先补齐能力，配具体行为目标。
**走不通：** 过度依赖证书时改成可展示的实际业务产出。

- [ ] 第4步的凭证已核实，并留在私人安全位置

### 第5步 · 选择晋升路径

**操作：** 比较内部晋升、内部转岗、外部竞聘三条路径的机会、周期、证明材料和风险。
**验收：** 一张三路径比较表与首选备选。
**走不通：** 组织无晋升窗口时，不长期押注单一路径。

- [ ] 第5步的凭证已核实，并留在私人安全位置

## 关键操作细化（完成需15—60分钟）

- **具体研究：** 从3份公开JD和公司合法公开资料摘出8项要求。
- **现实校准：** 为每项写“有证据/待补/不适用”，约一次校准。
- **证据等级：** A＝有合法可核验的书面/系统记录；B＝协作方可核对的纪要；C＝本人记忆或主观判断。C不可以包装为A。
- **怎么提问：** “我准备完成____，目前证据是____，缺口是____。你能否确认评价标准/授权边界/下一次反馈时间？”
- **失败时的止损：** 先列事实与不确定项，决定继续补资料、缩小试点或暂停；禁止为了凑结果伪造业绩/Offer。

## 交付包（建议不超过3页）

1. `level-gap.csv`：可复查的研究/决策记录。
2. 一页：背景、当前问题、数据口径、行动选择、完成日期。
3. 一页：关键反例、风险与下一步；涉及法律、聘用合同或重大财务风险先由相关专业人士核对。

## 质量门槛 / 自我审查

- [ ] 事实、推断、计划分别标记；不写保证结果。
- [ ] 每个数字都有单位、时间窗、归属、来源。
- [ ] 模板不包含真实密码、身份证号、客户信息和商业秘密。
- [ ] 至少写一个“当前假设失败会怎样”的替代动作。
