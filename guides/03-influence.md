# 第03章 · 拿到跨团队推动能力

越往上走，越需要在没有直接汇报关系的情况下推动协作。

> 读法：每步有具体操作、完成凭证、卡住怎么办。敏感资料只留在本人私有目录。

## 1. 画关键干系人地图

**具体操作：** 围绕一个业务目标找出使用者、决策人、资源方、风险控制方，记录对方关注点与同意标准。

**完成凭证：** 至少8人的干系人表，避免写敏感个人信息。

**卡住怎么办：** 不知道利益诉求时预约访谈，不根据性格标签猜测。

- [ ] 完成并留存合规凭证

## 2. 建立一页共识文档

**具体操作：** 写清问题、选项A/B、成本、边界、责任人和需要谁拍板，提前给相关人反馈。

**完成凭证：** 有日期版本号的一页决策文档。

**卡住怎么办：** 分歧过大先缩小范围，明确哪些问题尚无证据。

- [ ] 完成并留存合规凭证

## 3. 主持一次跨部门评审

**具体操作：** 会前收集分歧；会议上按事实、取舍、行动项走；会后24小时内记录责任人与截止日。

**完成凭证：** 会议纪要及被相关人确认的行动项。

**卡住怎么办：** 无法拍板就列升级条件和决策人，不自行冒充授权。

- [ ] 完成并留存合规凭证

## 4. 拆解一项资源冲突

**具体操作：** 记录资源不足导致的交付风险，量化优先级、替代方案和对其他团队的影响。

**完成凭证：** 可讨论的资源取舍方案，不指责个人。

**卡住怎么办：** 没有数字就用影响等级并说明判断依据。

- [ ] 完成并留存合规凭证

## 5. 积累被动认可证据

**具体操作：** 在项目结束时邀请相关协作者就具体行为给反馈，保留其愿意公开的部分。

**完成凭证：** 3条具体反馈，包含场景和行为。

**卡住怎么办：** 不强求好评，负面反馈也记入成长计划。

- [ ] 完成并留存合规凭证


## 深入实操：在没有管理权时推进协作

选择一个真实且获授权的跨部门任务。按照 **决策人D / 执行人O / 咨询者C / 知会者I** 建表，逐一询问目标、资源、不能接受的风险。这里的DOCI只是本项目的沟通工具，不是公司的正式组织授权。会议邀请中事先列清“今天需要达成哪两个决定”，会后24小时内发送行动项、owner、截止日、升级条件。

**决策备忘录六行**：现状是什么；不解决的后果；方案A/B；各自成本与受影响群体；建议方案；请谁在何时拍板。示例（虚构）：A方案两周发布覆盖60%需求，B方案四周发布覆盖85%；先核对用户风险和资源约束，再让有权负责人决定。没有权限不要自行批准预算。

**冲突应对话术**： “我理解你们这个月的优先级是X，我们需要Y。能否先用一个两天的最小试点验证风险？如果仍然冲突，周三一起交由项目负责人决定。” 不建议依靠私下施压、越级投诉或编造紧迫性。

**失败分支**：没人响应→缩小目标并提供只需选择A/B的文字决策；目标冲突→书面列取舍；决策权不清→请项目发起方确认；合作方明确拒绝→记录原因，不把“我协调过”写成“已经达成共识”。

**本章验收**：干系人地图、一次决策备忘录、一次明确责任人的复盘记录。

### 证据 E02 · 技术企业人员管理技能与离职（Hoffman & Tadelis，NBER 2018，2020修订）

**来源级别：** 学术研究。**样本/范围：** 一家大型高科技企业的人员数据与经理管理技能评价。

**真实观察：** 经理人员管理能力评分与员工离职率负相关；并非所有其他业绩指标都改善。

**外推限制：** 单企业研究；相关性及论文内的识别设计不能保证复制到你的团队。

**本章落地动作：** 保留1:1反馈、员工留任和培养记录；不得凭一次谈话宣称提高留存。
